# Journal — bitácora del proyecto

Una entrada por sesión de trabajo significativa, en Markdown, con nombre
`AAAA-MM-DD-tema.md` (si hay más de una sesión el mismo día, sufijo `-b`, `-c`).

Contenido mínimo de cada entrada — usarlo como checklist de cierre, a verificar
antes de commitear:

- [ ] **Contexto**: en qué hito del [ROADMAP](../ROADMAP.md) se trabajó.
- [ ] **Qué se hizo / qué cambió** (con referencias a commits, ADRs o archivos).
- [ ] **Decisiones tomadas** (las estructurales se formalizan además como ADR).
- [ ] **Pendientes y próximos pasos.**
- [ ] **Observaciones para el meta-análisis**: fricciones, sorpresas, comportamiento de
  los agentes, hipótesis que van surgiendo. Esta sección es la materia prima del
  capítulo de discusión — anotar acá lo que no encaja en ningún otro lado.

Las sesiones de asistencia con agentes de IA (p. ej. Claude Code sobre este repo)
también se registran: qué se le pidió, qué produjo, qué hubo que corregir.
